# 🛒 BazarDor — Daily Market Price Tracker

A one-stop platform for tracking daily prices of essential commodities, monitoring price fluctuations, and comparing prices across markets.

## Tech Stack
Next.js (App Router) · Tailwind CSS · DaisyUI · Better Auth · MongoDB Atlas · React Hot Toast · React Fast Marquee

## Key Features
- 📈 **Live Price Ticker:** Scrolling market prices with price increase/decrease indicators.
- 🏠 **Dynamic Homepage:** Top 6 products with the highest price increases and decreases, plus a complete product listing.
- 🗂️ **Category Pages:** Numeric price sorting, skeleton loading states, and custom 404 pages.
- 🔐 **Authentication:** Email, Google, and GitHub login with Better Auth; protected product detail pages.
- 📊 **Price Analytics:** Minimum, maximum, and average prices, with market-by-market comparisons.
- 👤 **User Profile:** Profile page with a form to update your name.
